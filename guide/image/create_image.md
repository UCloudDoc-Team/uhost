# 制作镜像

将账户下已有云主机实例的系统盘制作为自制镜像，保存操作系统、预装软件及配置，用于创建相同环境的新主机。



## 操作须知

- 若您选择了关联数据盘，会为关联的每块数据盘自动创建一个快照，系统盘镜像与这些快照组合起来构成一个自定义整机镜像。（经济型云盘、本地盘暂不支持该功能。）
- 关联数据盘需要开通快照服务，会产生一定的快照服务费用，涉及单独的计费，如您需要了解详情，请阅读[磁盘快照服务](https://docs.ucloud.cn/usnap/ivas)。
- 为保证数据一致性，建议停止主机内业务读写操作后制作；操作前备份重要数据，并清理不应随镜像复制的密码、密钥等敏感信息。
- 制作自制镜像前，不要随意修改网络等系统关键配置，以免镜像制作失败或制作的镜像无法启动。
- 自制镜像的价格和生成自制镜像的原镜像一致，例如，自制镜像从UCloud提供的CentOS 6.5上创建，则使用该镜像创建主机免费；若自制镜像从镜像市场的收费镜像创建，则从该自制镜像创建的主机仍然需要收取市场镜像的费用。用户的自制镜像将为用户长久保存在当前地域。关联数据盘的快照服务单独计费。

## 操作步骤

1. 登录 UCloud 控制台，切换至源主机所在项目和地域。
  
2. 进入【云主机】>【镜像管理】>【自制镜像】，点击【制作镜像】，选择源主机。或者在主机列表中选中想要制作镜像的实例，点击【…】>【更多操作】>【制作镜像】。（下图以第一种路径为示例）
  <img width="1853" height="907" alt="image" src="https://github.com/user-attachments/assets/3f0cd861-c9af-4b78-9037-c98dc8dec91e" />

3. 镜像来源能选择主机或快照，来源为快照的前提是需要源主机的系统盘开启了快照服务。
4. 填写镜像名称，按需选择关联的数据盘，点击【开启】。
5. 在【自制镜像】列表中查看具体制作进度，等待镜像状态变为【可用】。
6. 如源主机因本次操作停机，制作完成后按需启动并恢复业务。使用新镜像创建测试主机，检查启动、登录及应用运行情况；关联了数据盘的，还需检查数据盘挂载和数据。

镜像创建主机、复制、删除及使用范围等说明，请参见[自制镜像](image/common2.md)。
